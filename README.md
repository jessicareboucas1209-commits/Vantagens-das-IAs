### 🚀 Projeto em Destaque: Vantagens das IAs

Recentemente desenvolvi uma landing page focada em apresentar de forma visual e moderna os benefícios de 
se trabalhar com Inteligência Artificial na rotina de trabalho e estudos.

> **O que foi trabalhado nesse projeto:**
> * **Design UI/UX:** Transição de uma lista simples para um layout baseado em *Cards* modernos.
> * **CSS Avançado:** Uso de Flexbox para centralização perfeita e efeitos de `hover` interativos.
> * **Tipografia & Estética:** Integração com Google Fonts (Poppins) e sombras projetadas para profundidade visual.
